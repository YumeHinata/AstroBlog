## 工具准备：

幻梦是在Debian13上完成的解包操作，以下的笔记仅针对Debian系统环境。

这次解包的为 miwifi_rc01_firmware_5a1e1_1.1.56.bin

安装 SquashFS 和 Python3

```plain
sudo apt install squashfs-tools
sudo apt install python3 python3-pip pipx git
```

安装 ubi_reader

```plain
pipx install git+https://github.com/jrspruitt/ubi_reader.git
```

## 下载ROM：

[miwifi.com](https://www.miwifi.com/miwifi_download.html)

可以下载到最新的 rom 文件。

### 2.提取 UBI Volume

```plain
ubireader_extract_images miwifi_rc01_firmware_5a1e1_1.1.56.bin
```

```plain
UBI_File Warning: end_offset - start_offset length is not block aligned, could mean missing data.
```

可能会输出这样的警告，但是先不管他，`ls`看一下是不是生成了`ubifs-root`目录

一般目录的路径是这样的。

```plain
ubifs-root/
└── miwifi_rc01_firmware_5a1e1_1.1.56.bin/
    ├── img-1955263782_vol-kernel.ubifs
    └── img-1955263782_vol-ubi_rootfs.ubifs
```

他这个`.bin`结尾的真的是一个文件夹，是可以打开的。

### 3.确认 RootFS 类型

```plain
file ubifs-root/miwifi_rc01_firmware_5a1e1_1.1.56.bin/img-1955263782_vol-ubi_rootfs.ubifs
```

```plain
ubifs-root/miwifi_rc01_firmware_5a1e1_1.1.56.bin/img-1955263782_vol-ubi_rootfs.ubifs:

version 4.0, 
xz compressed, 
31643602 bytes,
```

说明这个 Volume 是一个完整的 SquashFS

### 4.解包 RootFS

```plain
unsquashfs \
-d rootfs \
ubifs-root/miwifi_rc01_firmware_5a1e1_1.1.56.bin/img-1955263782_vol-ubi_rootfs.ubifs
```
